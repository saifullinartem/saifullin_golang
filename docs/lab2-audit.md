# Сверка лабораторной 2 с условием

6 ноября 2026 года проверил работу по условию второй лабораторной,
соглашениям курса и каталогу телеметрии.

При проверке использовал
[условие ЛР2](https://github.com/course-go-autumn-2026/course/blob/main/homework/tasks/02-architecture-and-observability/README.md),
[соглашения курса](https://github.com/course-go-autumn-2026/course/blob/main/homework/docs/conventions.md)
и [каталог телеметрии](https://github.com/course-go-autumn-2026/course/blob/main/homework/docs/observability.md).

## Что проверено

| Требование | Что сделано и как проверено |
|---|---|
| Слои и зависимости | Код разделён по действиям, домен не зависит от транспорта и инфраструктуры. Импорты проверены через depguard и `go list` |
| Интерфейсы и сборка | Интерфейсы находятся у потребителей. Пул и репозитории создаются в `container`, main запускает и останавливает сервис |
| Домен и ошибки | Есть `Trip.Finish`, валидация и обработка ошибок через `errors.Is` и `errors.As`. Общий маппер формирует `Problem` без внутренних деталей |
| Unit-тесты и моки | gomock лежит рядом с кодом, `make generate` воспроизводим. Тесты проходят с `-race` и при повторном запуске. Покрытие domain/usecase 100% |
| Интеграционные тесты | Используется PostgreSQL с отдельными схемами, тегом `integration` и `-count=2`. Проверен полный rollback двух таблиц |
| Линтер | Все обязательные линтеры и форматтеры включены, замечаний нет |
| OpenTelemetry | Проверены HTTP- и SQL-спаны, метрики, экспорт по OTLP HTTP и gRPC, W3C-контекст и шаблоны маршрутов |
| Логи и Recover | В stdout пишется JSON с trace/span ID. На запрос приходится один лог. При панике сохраняется стектрейс, клиент и телеметрия получают 500 даже после частичной записи |
| Задание со звёздочкой | На одинаковом коде приложения исходные тесты обнаружили 29/37 мутаций, доработанные обнаружили 37/37. Все восемь выживших разобраны |

## Обработка ошибок

Ожидание закрытия пула ограничено общим `SHUTDOWN_TIMEOUT`.
Это проверяет тест с блокирующим ресурсом и отменой контекста.

Ошибка сериализации ответа проходит через общий маппер `Problem`.
Тест проверяет код, тип содержимого, скрытие внутренних деталей
и удаление `Location` от успешного ответа.

При ответе readiness с кодом 503 в HTTP-спане указывается `error.type`.
Tracing middleware записывает причину ошибки один раз.
Ответ readiness использует схему `HealthResponse`.

Интервал экспорта метрик SDK читает из
`OTEL_METRIC_EXPORT_INTERVAL`, в примере указано 5000 мс. Логгер для ошибок
запуска создаётся в контейнере, поэтому main не импортирует инфраструктуру.

## Результаты запусков

В [журнале проверок](evidence/audit/checks.json) записаны команды, время
и коды завершения. В него вошли `go build ./...`, `make generate`,
`make lint`, `make test`, повторный запуск unit-тестов,
`make test-integration` и мутационные проверки.
Хеши сгенерированных файлов до и после `make generate` совпали.

Полный вывод есть в логах
[сборки](evidence/audit/final-build.txt),
[линтера](evidence/audit/final-lint.txt),
[unit-тестов с покрытием](evidence/audit/final-unit.txt)
и [повторного запуска с -race](evidence/audit/final-repeat.txt).
Отдельно записано [состояние окружения](evidence/audit/environment.txt).

При запуске с [OTLP HTTP/protobuf](evidence/audit/runtime-http.json)
прошли 13 HTTP-проверок. В Jaeger появился трейс из пяти спанов,
в Prometheus появилась метрика 405. Процесс завершился с кодом 0.

При запуске с [OTLP gRPC](evidence/audit/runtime-grpc.json)
прошли 14 HTTP-проверок. В Jaeger появился трейс из пяти спанов,
в Prometheus появилась отдельная метрика PATCH/405.
Процесс завершился с кодом 0.

[Без коллектора](evidence/audit/collector-unavailable.json) новый процесс
запустился, создал, прочитал и завершил поездку, затем остановился с кодом 0.
После проверки коллектор восстановлен. В [stdout приложения](evidence/audit/collector-unavailable-service.jsonl)
все записи имеют формат JSON и обязательные поля.
Диагностика SDK из stderr сохранена [отдельно](evidence/audit/collector-unavailable-sdk-stderr.log).

При [запуске без DATABASE_URL](evidence/audit/bootstrap-error.json)
процесс завершился с кодом 1 и записал JSON-лог уровня Error.

[Статическая проверка](evidence/audit/static-checks.json) не нашла запрещённых
импортов, изменений контрактов и миграций, `.env` в истории Git и известных
шаблонов приватных ключей и токенов. Поиск по шаблонам не гарантирует
отсутствие всех возможных секретов.
